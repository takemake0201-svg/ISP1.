# ISP-Ⅰ v0.11.5 — クラウドデータ保存一時停止版

改修元: ISP-I-v0.11.3-diagnostics-prototype(1).zip （v0.11.4 は使用していません）

## 変更点
- クラウドデータ保存・復元・クラウド内容確認を無効化。
- 自動同期設定が過去にONでも、同期処理を実行しない。既存の設定値は消去しない。
- クラウドデータの通信関数にガードを追加し、意図しない読み書きを防止。
- クラウド紐付け・整合性診断を一時停止。
- 設定画面に一時停止の説明を表示。

## 維持するもの
- ローカルデータの保存と編集、JSONバックアップ・復元
- Supabase Auth、Web Push関連コード・通信
- Supabase上の既存の保存データ（削除処理なし）
- v0.11.3 のログイン・設定画面構造（v0.11.4 の変更は含まない）

## 注意
- PCとAndroidのデータは自動的には同期されません。端末ごとにJSONバックアップを取得してください。
- 端末内保存はブラウザのストレージに依存します。ブラウザデータ削除前に必ずJSONを書き出してください。
- 以前のクラウド同期設定は保持されますが、この版では常に無効です。
- 既存のWeb Push不具合や認証・領域切替不具合の修正を保証するものではありません。
- 実機での動作確認は未実施です。
