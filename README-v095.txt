ISP-Ⅰ Ver.0.9.5：自動同期・運用診断試験版

Ver.0.9.4bを基準に、同期状態の履歴（端末内最大30件）、通信状態表示、競合時の手順案内、自動復元前バックアップの書き出しを追加。
認証セッションは従来通りページ再読込で終了します。ログイン状態維持は未実装です。
通信復帰時の再確認は従来の自動同期機構を使用します。ブラウザを完全に終了している間の同期はできません。

【試験】
1. 0.9.4bでJSONバックアップを取得。GitHub Pagesへ更新（サイトデータを削除しない）。
2. Supabaseへログイン。両端末の同期基準を手動でそろえる。
3. 自動同期ONでテスト用ToDoを作り、反映を確認。
4. Edge DevTools → Network → Offline に切り替える（または端末の通信を一時的に切る）。
5. オフライン中にテスト用ToDoを追加。端末内で保持されることを確認。
6. Onlineへ戻し、アプリを開いたまま同期状態を確認。約20～60秒程度待つ。
7. 両端末同時編集の場合は競合停止が起きることを確認。クラウド内容を勝手に上書きしない。
8. 「同期履歴を表示」で状態履歴を確認。

【注意】
重要データを使わずに試験。ブラウザのサイトデータを消すとローカルデータが失われます。
DevToolsのOfflineはブラウザ全体のネットワークを遮断するとは限りません。navigator.onLine表示は参考値です。
