# ISP-I v0.11.2 Web Push認証修正

- 通知ポップアップからのWeb Push登録・テスト送信・解除は、まず同一オリジンかつ同じSupabaseプロジェクトのメイン画面から認証トークンを取得します。メイン画面が直接参照できない場合は既存のBroadcastChannel認証共有を試します。
- 通知送信の認証確認だけを目的とする場合、ポップアップ側でデータ領域を切り替える処理を先に呼び出さないよう変更しました。
- 認証更新時に同じデータ領域を再度切り替えないようガードを追加しました。実際にアカウントが変わる場合の未保存・同期・競合保護は維持します。
- 通知画面を使う際は、Supabaseにログイン済みのISP-Iメイン画面を開いたままにしてください。
- 静的構文検査のみ実施。Supabase実サーバーとの接続・通知到達は未検証です。
