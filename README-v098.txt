ISP-Ⅰ Ver.0.9.8 アカウント別ローカル領域・バックアップ保護

重要：Ver.0.9.7のJSONバックアップを先に保存。
旧データは ispi-v02-data に残り、ログアウト中は旧データ領域として表示されます。
ログインすると Supabase URLホスト名＋ユーザーIDごとのローカル領域に切り替わります。初回は空です。
旧データのアカウント紐付け先が一致する場合だけ「旧データをコピー」が可能です。
コピー後はクラウドへ自動アップロードしないようブロックします。クラウドを確認してから同期してください。
JSONバックアップに _ispBackup メタ情報を付与します。旧形式・異なる所有者のJSONを復元する際は警告を表示します。
注意：端末データは暗号化されません。旧データ領域はログアウト時にも見えるため共有端末では利用しないでください。
Supabase RLSのユーザーID所有者ポリシーは既存のままです。SQL再実行不要。
検証：アカウントA/B切替、旧データコピー、JSON復元警告、同期競合、オフライン復帰。
