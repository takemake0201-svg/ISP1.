ISP-Ⅰ Ver.0.9.2 手動クラウド同期試験版
1. 先に現行アプリからJSONバックアップを保存する。
2. Supabase DashboardのSQL Editorで SUPABASE-SQL.sql を実行する。
3. ZIPの index.html, sw.js, manifest.webmanifest, icons/ をGitHub Pagesの既存リポジトリに上書きする。SQLファイルを公開リポジトリに置く必要はない。
4. 更新後、設定→クラウド連携・認証でログインし、クラウドへ保存→別端末でログイン→クラウドから復元を試す。
5. データの自動統合は行わない。クラウドへ保存すると直前のクラウドデータを上書きする。復元は端末データを置換する。
注意: パスワードやservice_role/secret keyをGitHubへアップロードしない。端末のブラウザデータを削除しない。
制限: 認証セッションは再読み込みで終了。アクセストークン期限切れ時は再ログインする。実通信・複数端末での検証は未実施。
