# ISP-Ⅰ v0.11.8 認証・端末データ領域切替の分離

- ベース: v0.11.7（クラウドデータ保存一時停止、ToDo完了即時削除、端末内システムログ）
- Supabaseのログイン成功・セッション復元・トークン更新は、端末内データ領域の切替失敗によって取り消されません。
- 領域切替が安全に実行できない場合、ログインを維持し、端末内の現在の領域を保持します。画面に警告と「領域切替を再試行」ボタンを表示します。
- 競合・未保存編集・同期処理がある場合、既存のprofileSwitchの安全判定は維持します。認証を理由にデータを破棄・上書きしません。
- ログアウト時も強制リロードを行いません。領域切替できない場合は保留します。
- クラウドデータ同期は引き続き一時停止です。Web Push向けSupabase Authは維持します。

## 注意事項
領域切替が保留中の場合、現在表示しているローカル領域はログイン中のSupabaseアカウント専用領域とは限りません。端末を共有する場合は現在のデータを他人に見せないよう注意してください。クラウドへのデータ同期は無効です。

## 確認事項
1. 編集途中でログインし、ログイン成功と領域切替保留の表示を確認。
2. 編集内容が保持されることを確認。保存・競合解決後「領域切替を再試行」。
3. 再読み込み後のセッション復元と端末内データの保持を確認。
4. ログアウト時の強制リロードがなく、データが保持されることを確認。
5. システムログ、ToDo即時削除、Web Push、クラウド同期停止を確認。
