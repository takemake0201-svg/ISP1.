# ISP-Ⅰ v0.11.1 認証セッション保持表示の修正

ベース：v0.11.0-settings-redesign-prototype

- 設定画面の再描画時に、実際の認証セッション保持モードを選択欄へ反映します。
- ログイン成功時・セッション復元時にも選択欄を同期します。
- ログイン中に保持方法を変更した場合、保存先（メモリ／タブ／端末）を即時更新します。
- ログアウト時は表示を「保持しない」に戻します。
- 端末に保存するトークンの形式やSupabase認証APIは変更していません。

確認：ログイン→設定トップへ戻る→アカウント設定を再表示→F5再読み込み→ブラウザ再起動。
注意：この環境では実際のSupabaseログインとWeb Push受信試験は行っていません。
