ISP-Ⅰ Ver.0.9.0 — クラウド同期の設計・接続準備版

このバージョンにはクラウド同期・アカウント認証・プッシュ通知は実装されていません。
設定 → クラウド連携（準備）で端末環境を確認し、同期準備用JSONを手動出力できます。
JSONは端末にダウンロードされ、ネットワーク送信は行いません。

GitHub Pagesへの更新：
1. 既存のVer.0.8.3aのJSONバックアップを手元に保存する。
2. このフォルダ内の index.html、manifest.webmanifest、sw.js、icons/ をGitHubのリポジトリ直下に上書きアップロードする。
3. GitHub Pagesのデプロイを待ち、必要に応じてアプリを再起動する。
4. 設定 → クラウド連携（準備）を開いて表示を確認する。
5. ToDo・授業・スケジュール・ICS出力・バックアップ復元の回帰試験を実施する。

安全上の注意：
- 個人情報入りのJSONファイルをGitHubへアップロードしない。
- GitHub Pagesは静的サイトであり、単独で個人データの同期はできない。
- PCローカル版とGitHub Pages版のデータは自動共有されない。
- 本番クラウド接続はサービス選定、認証・権限設計、同期競合・削除設計を確定してから実装する。
