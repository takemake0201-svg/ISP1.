# ISP-Ⅰ Ver.0.10.0 — Android通知 第1段階

Ver.0.9.9からの変更：通知許可、Service Worker状態確認、手動テスト通知、通知クリックによるISP-Ⅰ起動。

## 配置
ZIPを展開し、index.html、sw.js、manifest.webmanifest、icon.svgを同じGitHub Pages公開フォルダーに配置してください。既存の index.html のみ置き換えると動作しません。

## 確認
1. 変更前に設定→データ管理からJSONバックアップを保存。
2. Androidのホーム画面のISP-Ⅰを起動。更新が反映されない場合はChromeでページを再読み込み。
3. スマートフォン通知機能→環境を確認→通知を許可する→テスト通知を表示。
4. 通知をタップしISP-Ⅰが開くか確認。

## 未実装
サーバーPush、アプリを閉じた状態での予約通知、ToDo/授業との自動連動、Push購読情報保存。ICS方式は継続。

## 注意
既存のService WorkerはVer.0.9.9配布物に含まれていませんでした。今回のsw.jsはキャッシュ操作を行いません。通知表示やタップ後の動作は実機で検証してください。
