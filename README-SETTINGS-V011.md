# ISP-Ⅰ v0.11.0 設定画面再編（試作版）

ベース: v0.10.3-todo-week-view

- 設定トップを5カテゴリのカード型画面に変更。
- 各カテゴリの専用画面に切替・設定トップへ戻る操作を追加。
- Supabase認証フォームをアカウント設定に移設（既存の認証処理を使用）。
- データ管理・拡張機能・クラウド連携の既存処理を維持。
- スマートフォン通知を拡張機能の追加候補から除外し、設定の「通知機能」に配置。

- ICS出力UIを通知画面から非表示（出力関数は保持）。

- 実ブラウザでのSupabase接続、Web Push、端末間同期は未検証です。既存データのバックアップを保存してから試してください。
