ISP-Ⅰ Ver.0.9.9 — 復旧・障害診断試験版

変更点：アカウント領域別のローカル復旧ポイント、最大12件・約2MB、10分間隔以上の編集後自動保存と15分ごとの確認、復旧履歴一覧・JSON書き出し・復元前確認・ローカル診断。

注意：復旧履歴はlocalStorageに保存します。ブラウザのサイトデータ削除、端末故障、ストレージ容量不足に備えるため、必ず外部JSONバックアップも保管してください。
復元後はクラウド自動同期を停止し、データを確認してください。

試験：1) 旧版JSON保存 2) 新版起動 3) 復旧ポイント作成 4) ToDo追加 5) 復旧ポイントから復元 6) JSON書き出し 7) アカウント切替で履歴分離 8) オフラインで復旧可能か確認。

Supabase SQLの変更はありません。実ブラウザ試験は未実施です。
