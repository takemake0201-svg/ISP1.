# ISP-Ⅰ v0.11.6 — ToDo完了時の即時削除

改修元: v0.11.5（v0.11.3ベース、クラウドデータ保存一時停止版）

- ToDoの「完了」ボタンを押すと、該当ToDoを端末内の一覧から即座に削除して保存します（追加の確認画面なし）。
- 保存失敗時はToDoをメモリ上で元に戻します。
- 操作履歴には「ToDo完了・自動削除」を記録します（タイトルを含みます）。
- 旧版で既に完了済みのToDoは、起動時等のクリーンアップで削除します。
- 「完了済」フィルターは削除しました。以前の完了済ToDoを保持したい場合は、**更新前にJSONバックアップ**を取得してください。
- クラウドデータ保存・復元・自動同期の一時停止方針は変更していません。
- 端末間のデータ同期は行いません。

注意: 完了直後の取り消し機能はありません。重要なToDoは事前にJSONバックアップを取ってください。
