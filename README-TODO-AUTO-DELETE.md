# ISP-Ⅰ ToDo完了後24時間自動削除（v0.10.2 機能追加版）

- ToDoの「完了」操作時に `completedAt`（ISO 8601形式）を記録します。
- 完了後24時間が経過したToDoを、起動時・画面描画時・定期確認時・フォーカス復帰時に自動削除します。
- 24時間以内に「未完了に戻す」を押すと `completedAt` を削除し、削除予定を取り消します。
- 旧版で完了済みのToDo（完了日時がないもの）は、更新後の初回確認時から24時間保持します。既存の完了日時は推定しません。
- 自動削除は端末内の現在のプロフィール領域に保存されます。クラウド上のデータへ反映するには既存の同期機能で保存してください。
- アプリを開いていない間は削除処理は実行されません。次に開いたときに期限切れのToDoを削除します。
- ブラウザの時計を利用します。端末の時計が正しく設定されている必要があります。

## 注意
削除後のToDoは通常の一覧からは復元できません。必要に応じて事前にJSONバックアップを保存してください。複数端末のクラウド同期では、他端末の古いバックアップを復元すると削除済みToDoが再登場する場合があります。
