# ISP-Ⅰ v0.11.4 — Supabaseログイン統合試作版

- ホームのデモ認証をSupabase Authのパスワード認証に変更。
- 初回接続設定と認証セッション保持モードをログイン画面に追加。
- ログイン成功後に認証UIDのデータ領域へ切替。領域切替失敗時はホームを開かない。
- ログアウトで認証セッションを破棄。
- 旧ゲストデータや既存アカウントデータを自動移行・削除しない。

## 注意・未検証
- Supabase接続・Web Push・別ウィンドウの動作は実機未検証。
- 「保持しない」は再読み込みでログアウトします。別ウィンドウを使う場合は「この端末に保持」を選んで試験してください。
- ログイン用トークンのブラウザ保存にはXSS・共有端末リスクがあります。
- Supabase側のRLS設定は別途確認してください。
- 既存データはログインによって自動移行されません。操作前にJSONバックアップを作成してください。
