# ISP-Ⅰ Windows Web Push 認証修正

- 対象: Windows版でクラウド保存・復元は成功するが、別ウィンドウのWeb Push登録で「Supabaseにログインしてください」と表示される問題。
- 変更: `index.html` のWeb Push専用認証取得処理を修正。同一オリジン・同一Supabaseプロジェクトの起動元ウィンドウから、有効な認証セッションを都度取得します。
- 既存のクラウド保存・復元、Android端末内通知、ICS出力、Supabaseサーバー設定は変更していません。
- 使用手順: 先にJSONバックアップを取得し、ZIP内の公開用ファイルをGitHub Pagesに上書きしてください。Windowsでメイン画面を開いてSupabaseにログインし、メイン画面から「スマートフォン通知機能」を開き直してPush登録を試してください。
- 既に開いている通知ウィンドウは閉じてください。直接URLで通知ウィンドウを開くと、メイン画面からのセッション取得はできません。
- 注意: JavaScript構文検査は実施しましたが、Windows実機でのWeb Push登録は未検証です。共有PCでは「この端末に保持」を安易に選択しないでください。
