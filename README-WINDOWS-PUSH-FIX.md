# Windows Push 認証修正 v2

Edge PWAでwindow.openerが利用できない場合のため、同一オリジンのBroadcastChannelを使った一時的な認証共有を追加しました。

1. JSONバックアップを取得
2. ZIP内のWeb公開ファイルをGitHub Pagesへ更新
3. すべてのISP-Ⅰウィンドウを閉じて更新後のメイン画面を起動
4. メイン画面でSupabaseクラウド認証を確認し、閉じずに通知画面を開く
5. Web Push登録を再試験

メイン画面を閉じた状態ではメモリ保持の認証は共有できません。
認証情報はブラウザストレージに追加保存しません。
同一オリジンの他スクリプトが存在する場合はBroadcastChannelの共有情報へアクセスできるため、同一オリジンに信頼できないアプリを公開しないでください。
実機試験は未実施です。
