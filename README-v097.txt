ISP-Ⅰ Ver.0.9.7 クラウドデータ保護・整合性強化

【更新】
GitHub Pages の公開ファイルを上書きしてください。更新前に Ver.0.9.6 の JSON バックアップを保存してください。

【追加】
・アカウントごとの端末データ紐付け（初回は明示的な確認が必要）
・別アカウントへログインした場合のクラウド同期停止
・端末とクラウドの読み取り専用整合性診断（データ件数と内容比較）
・通信中のアカウント切替検知

【重要な制限】
・端末内データはブラウザの同じ保存領域で共有され、アカウントごとの閲覧分離・暗号化はしていません。
・アカウント切替前には必ず JSON バックアップを取得してください。
・紐付けは端末データをそのアカウントに同期する許可であり、データの移動・分離ではありません。
・同期の競合時には自動統合せず停止します。
・Supabase SQL を自動変更していません。

【試験】
1. ログイン後、クラウド同期は「未紐付け」で停止することを確認。
2. JSONバックアップを保存して紐付け。従来の手動・自動同期を確認。
3. 整合性診断で一致または差異を確認。
4. 別の試験用アカウントでログインし、同期が停止することを確認。
5. 元のアカウントに戻り、再び同期できることを確認。
6. オフライン・復帰試験、競合防止試験を実施。

【Supabase セキュリティ診断での警告】
・public.rls_auto_enable() の anon/authenticated への EXECUTE 権限。管理者と検討して REVOKE を実施してください。
・漏えいパスワード保護が無効。Supabase Dashboard の Auth 設定で有効化を検討してください。
